V3.5 Agent Context

用 server 级模板复用常用 AGENTS.md，用 project snapshot 固定每个项目真正执行的规则。

核心判断

模板可复用常用 agent prompt 不应散落在每个 project 表单里，应成为 server DB 中可管理的 template。
项目要快照创建 project 时复制模板并可微调；后续模板变化不影响旧 project。
运行时落盘dispatcher 在 workspace 写 AGENTS.md；driver 只负责 Pi 是否加载 context files。

数据流

Templateserver-wide 常用规则库
Project Create选择模板并微调
Snapshotproject-scoped 执行真相
Materialize写入 workspace/AGENTS.md
Pi Run开启 context files

边界

做
  • 表名/API 使用 agent_context，MVP kind 只允许 agents_md。
  • execution metadata 记录 hash/path。
  • 既有 AGENTS.md 冲突时拒绝静默覆盖。
不做
  • 不做 MCP、extensions、skills、prompt templates。
  • 不按 model/worker/endpoint 分叉注入。
  • 不让 driver 拥有模板来源或 DB 语义。
