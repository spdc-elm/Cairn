V3.3 Frontend Refactor
Spec Draft 2026-05-20

不是换框架。是把 UI 从全能脚本改成可测投影层。

展示能力基本不变；事实源更单一；状态边界更清楚。v3.3 的第一约束不是工期，而是重构后 Graph、Log、Output、Ask 仍指向同一真实对象。

验收口径：用户可见工作流与语义不退化，非像素级一致。

当前病因

单文件边界坍缩

`index.html` 同时承载模板、状态、API、图布局、conversation、healthcheck、replay、modal。

事实解释外溢

浏览器端仍解析 worker stdout，并把 ExecutionEvent 投影成多套 UI 语义。

测试护栏偏弱

字符串守卫能防删调用，不能证明页面能跑、图非空、点击有效、布局不破。

不可退让的不变量

Fact/Intent DAG仍是用户心智模型，不被 execution list 替代。
ExecutionEvent仍是 Output 与 Conversation 的实时事实源。
Branch表达 fork/resume/fresh_context 的连续线。
Selection ParityGraph、Detail、Log、Output、Ask 不错锚。
Raw Fallbackparser 漂移时仍有最后可信视图。

重构边界

前端边界

  • ApiClient
  • ProjectionContracts
  • GraphSelectionStore
  • GraphModelAdapter / GraphCanvas
  • ExecutionStreamStore
  • Conversation / QuestionBranch / Timeline

服务端边界

  • `/ui-projection` 有明确 response model
  • Transcript normalization 下沉到 server/shared
  • Ask availability 来自 capability + session + health
  • 前端不按 worker type 猜能力

测试先行

Contract

FastAPI TestClient 覆盖 graph projection、events cursor、branches、worker capability、healthcheck request。

Unit

抽出 buildElements、selection reducer、event view model、conversation compaction、question availability。

Browser / Visual

Playwright 或等价 smoke：创建项目、图非空、Output 实时、Ask、healthcheck、窄屏无溢出。

待决策

技术底座

  • Alpine + ES modules 过渡
  • React + TypeScript + Vite 为长期推荐
  • Vue/Svelte/Lit 皆可，但状态边界先行

验收底座

  • `/ui-projection` 取代 `/graph` 主命名
  • Playwright 纳入仓库，或 Browser MCP 过渡
  • 视觉基线是否进入 CI
